# 机器学习核心概念速查卡

配合吴恩达课程使用。目标是"能用自己的话讲清楚"，不是背定义。

## 1. 监督学习

- **回归**：预测连续值（房价、温度）。
- **分类**：预测离散类别（是否存活、猫/狗）。
- 数据 = 特征 `X` + 标签 `y`。模型学的是 `X → y` 的映射。

## 2. 代价函数与梯度下降

- **代价函数**（loss）衡量预测有多差。回归常用均方误差：`MSE = mean((y_hat - y)^2)`。
- **梯度下降**：沿着损失下降最快的方向更新参数：

  `w ← w - lr * d(loss)/dw`

- **学习率 lr**：太大 → 震荡不收敛；太小 → 收敛极慢。实际中常用 Adam 自动调节。

## 3. 过拟合、欠拟合与偏差-方差

- **欠拟合**（高偏差）：模型太简单，训练和验证误差都高。
- **过拟合**（高方差）：模型太复杂/数据太少，训练误差很低，验证误差高。
- **诊断方法**：对比训练误差与验证误差。
  - 两个都高 → 欠拟合：加特征、换更复杂模型。
  - 训练低、验证高 → 过拟合：加正则化、加数据、降复杂度。
- **正则化**：在损失里加参数惩罚（L2 惩罚 = weight decay），逼模型"简单一点"。

## 4. 数据划分：train / val / test

- **训练集**：用来学习参数。
- **验证集**：用来选超参数、选模型（如学习率、正则化强度）。
- **测试集**：只允许最后用一次，模拟"没见过的新数据"。
- 用测试集调参 = 数据泄漏，测试分数会虚高。

## 5. 交叉验证

- 把训练集切成 K 份，轮流拿 1 份当验证集，其余训练；最后取平均。
- 优点：数据利用更充分，评估更稳；缺点是训练 K 次，慢。
- 小数据集、选模型阶段常用；深度学习时代通常直接用一次 train/val 划分。

## 6. 评估指标

- 分类：**accuracy**（准确率）、**precision/recall/F1**（类别不平衡时看）、**ROC-AUC**（排序能力）。
- 回归：**RMSE/MAE**（误差大小）、**R²**（解释了多少方差）。
- 指标要跟业务/科研问题匹配：比如"罕见病检测"更看重 recall 而不是 accuracy。

## 7. 数据预处理

- **标准化**：把特征缩放到均值 0、方差 1，加速收敛。
- **只对训练集 fit，再 transform 验证/测试集**——否则验证集信息泄漏进训练。

## 8. 第 1 周必答的三个问题

1. 训练曲线：训练 loss 一直降、验证 loss 先降后升，说明什么？
   → 过拟合，训练到后面模型在"背"训练集。
2. 为什么先划出验证集再调参？
   → 避免把验证集当测试集用，最后测试分数才可信。
3. 随机森林和线性回归哪个更容易过拟合？为什么？
   → 随机森林（深度不限制时）容量更大，更依赖正则化（限制深度/叶子数）。
