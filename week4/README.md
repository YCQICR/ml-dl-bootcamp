# 第 4 周：论文阅读与收尾

> 预计投入：20–25 小时（ResNet 精读 10h + Transformer 背景 5h + 整理仓库 5h + 实验报告 4h）
> 验收标准：能用 15 分钟讲清 ResNet 的方法；GitHub 仓库可复现。

## 本周任务

- [ ] 按 `paper_reading_guide.md` 的三遍法读完 ResNet 论文（[arXiv:1512.03385](https://arxiv.org/abs/1512.03385)）
- [ ] 用 `paper_card_resnet_example.md` 当模板，写自己的论文卡片
- [ ] 读《The Illustrated Transformer》并对照 `transformer_notes.md` 整理笔记
- [ ] 把三周代码整理进 GitHub（README、运行说明、曲线、指标）
- [ ] 用 `report_template.md` 完成一页实验报告
- [ ] 对着"15 分钟讲解提纲"练习讲一遍 ResNet
